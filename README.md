# Employee Exit Analysis

## Project Overview

This project analyzes employee turnover and exit trends using **Excel, SQL, and Power BI**.

The goal is to identify patterns in employee exits and provide insights that can support better workforce planning and employee retention decisions.

## Tools Used

- **Excel** – Data cleaning and initial analysis
- **SQL** – Data querying and analysis
- **Power BI** – Interactive dashboard and data visualization

## Key Metrics

- Total Employees: 2,404
- Current Employees: 1,150
- Employees Exited: 1,254
- Employee Exit Rate: 52.2%

## Analysis

The project explores employee exits across:

- Business divisions
- Job titles
- Termination types
- Employee turnover patterns

## Dashboard

The Power BI dashboard provides an interactive view of employee exit trends, with filters for **Division** and **Job Title**.

## Project Files

- `Employee_Exit_Analysis.xlsx` – Excel analysis
- `Employee_Exit_Analysis.sql` – SQL queries and analysis
- `Employee_Exit_Analysis.pbix` – Power BI dashboard

## Key Insights

The analysis highlights differences in employee exits across divisions, job titles, and termination types, providing a data-driven view of workforce turnover.

**Data Cleaning | Data Analysis | SQL | Excel | Power BI | Data Visualization | Business Insights**
